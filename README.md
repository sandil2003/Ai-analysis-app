An all-in-one AI-powered application built with React, TypeScript, and the Google Gemini API. This suite features multiple AI capabilities including image detection, image editing, and conversational AI.

## ✨ Features

### 🔍 AI Image Detector
- **Detect AI-Generated Images**: Analyze images to determine if they were created by AI or are real photographs
- **Probability Scoring**: Get detailed probability scores and explanations
- **Drag & Drop Upload**: Easy-to-use interface for uploading images
- **Real-time Analysis**: Instant results powered by Gemini's vision capabilities

### 💬 AI Chatbot
- **Conversational AI**: Engage in natural conversations with an intelligent chatbot
- **Context-Aware**: Maintains conversation history for coherent interactions
- **Powered by Gemini**: Leverages Google's advanced language model
- **Clean UI**: Modern chat interface with message history

## 🚀 Getting Started

### Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v18 or higher recommended)
- **npm** (comes with Node.js)
- **Gemini API Key** (Get one from [Google AI Studio](https://makersuite.google.com/app/apikey))

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd Ai-analysis-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   
   Create a `.env.local` file in the root directory:
   ```bash
   GEMINI_API_KEY=your_api_key_here
   ```
   
   Replace `your_api_key_here` with your actual Gemini API key.

4. **Run the development server**
   ```bash
   npm run dev
   ```

5. **Open your browser**
   
   Navigate to [http://localhost:3000](http://localhost:3000)
